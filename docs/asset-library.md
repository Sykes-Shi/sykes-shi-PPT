# 本地素材库：选择、导入和使用

本项目提供 PPT 制作方法，不附带模板、图片、标识和其他素材。你可以在本机准备自己的素材库，并在每次任务中指定参考文件或素材库路径；也可以只上传本次需要的文件。本指南中的目录和索引是可自行采用的示例，本项目没有自动导入或后台扫描功能。

## 1. 准备哪些素材

优先收集有权使用、质量稳定、未来会反复用到的材料，不需要为了丰富数量收集大量相似模板。

| 类型 | 适合放入的材料 | 用法 |
| --- | --- | --- |
| 主要模板 | 常用母版、主题、可编辑 PPTX 或 POTX | 决定画幅、配色、字体、标题、页脚等基础视觉规则。 |
| 成功案例 | 已认可的汇报、方案、技术交流稿 | 用来参考概览、比较、时间线、架构等具体版式。先检查当前内容是否适用。 |
| 图片与标识 | 获准使用的标识、照片、图标和背景 | 以原文件形式使用；真实标识和证据截图优先使用原件。 |
| 补充参考 | PDF、页面截图、风格样图 | 用于参考构图和表达。PDF 与截图不能直接当作可编辑 PPTX 母版。 |
| 数据与事实 | 本次任务的资料、数据表、真实截图和说明 | 为当前汇报提供事实依据，与历史风格参考分开；按项目管理，不必长期存入公共模板库。 |

值得加入的材料包括新版本模板、经过实际使用且希望复用的页面，以及现有库无法覆盖的常见场景。更新前核对来源和使用范围，保留源文件，不覆盖已有参考；对含敏感信息的参考，索引和预览也应按相同要求保护。

完成某次汇报后，如果希望把认可的成品纳入长期参考，需要在任务中明确提出，并指定保存位置。可让 Codex 提炼其中适合复用的页面类型和设计逻辑；后续任务仍以新提供的事实为准。只要求使用技能时，不代表已指定某一份模板。

## 2. 在本机组织素材

选择一个你有权限管理、适合保存私人资料的本地目录。素材库与项目和技能安装目录分开放置，无须把它放进 Git 仓库。以下仅为示意，名称和层级均可调整；索引和预览单独放在云同步目录以外：

```text
我的PPT素材库/
├─ 模板/                 # 常用 PPTX、POTX
├─ 参考案例/             # 经许可保留的演示文稿
├─ 图片与标识/           # 授权图片、标识等
└─ 补充参考/             # PDF、截图等

PPT索引与工作区/          # 云同步目录外、公开仓库外
├─ 预览/                 # 在本机生成的缩略图或预览
└─ 索引.md               # 源素材库根目录、用途、位置与页码
```

例如，可以自行选择本机的 `D:\个人资料\PPT素材库` 或其他合适位置；该路径只是示例，使用时换成自己的实际路径。路径和文件名无需与上面的目录完全一致。

**云同步文件的处理：**如果原始材料存放在云同步目录，先将本次需要的输入复制到云同步范围外的工作区，再生成预览、索引、临时文件和成品副本。只有用户明确需要的最终文件才写回云端；不要为整理素材擅自移动、删除或清理云端原件。

## 3. 建立简单索引

索引帮助 Codex 找到合适参考，也让你记住每份文件的用途。索引开头应记录**源素材库的实际根目录**；下表的相对路径均相对于该根目录，而不是索引文件所在目录。记录实际存在的材料即可，页码按演示文稿的显示顺序填写；没有可编辑源文件时写明文件类型。如果原件在云同步目录，索引指向原始文件位置，使用时按任务复制所需文件到工作区，不把临时副本当作长期来源。

示例索引开头：`源素材库根目录：D:\个人资料\PPT素材库`。移动素材库后，需更新这一记录；真实索引可能包含私人路径，应仅保存在适当的本地位置。

| 材料名称或相对路径 | 主要用途 | 可参考页面 | 类型与使用边界 |
| --- | --- | --- | --- |
| `模板/正式汇报.pptx` | 主要视觉模板 | 封面、正文、结束页 | 可编辑；以母版和标题样式为准。 |
| `参考案例/方案比较.pptx` | 比较方案和进度 | 比较页 4、计划页 7 | 借鉴布局；旧数据和结论不用于新任务。 |
| `补充参考/图示参考.pdf` | 参考架构图 | 第 5 页 | 视觉参考；如需编辑，基于当前事实重新制作。 |

可以在索引中补充画幅、预览位置、可否公开或其他使用条件。不要把索引、缩略图或从文稿提取的正文提交到公开仓库：即使素材原件没有上传，这些衍生内容也可能包含敏感信息。

## 4. 让 Codex 协助整理

把下面提示词中的路径和范围替换成自己的实际信息。Codex 需要能访问所选路径，所用环境也需要具备读取和渲染相应文件的能力。

```text
$sykes-shi-ppt 请帮我整理本机 PPT 参考素材。
素材来源：[填写文件或素材文件夹的实际路径]
本地工作区：[填写云同步目录之外的路径]

请只读取我指定的材料，保留源文件，不移动、不覆盖、不删除原件。
按用途检查模板和参考案例，在本地工作区生成适当的预览和一份索引，索引开头写明
源素材库根目录；使用相对于该根目录的路径，记录适用场景、代表页码、文件类型
以及使用边界。区分可编辑 PPTX 和 PDF／图片参考；
不要把历史内容当作当前事实，不要将素材、预览或索引上传到公开仓库或外部服务。
若发现无法读取、来源不明或需要我确认权限的文件，请列出来。
```

以上提示词授权的是对指定材料的整理和本地工作区内的输出；如需长期保存、复制到素材库或更新已有索引，应明确写出目标位置和允许的操作。对已有索引或文件的替换，也请先确认原文件未被其他操作修改。

## 5. 在新任务中使用

在任务中指定你希望使用的素材库、索引或某份文件，并说明它是**唯一模板**、**风格参考**还是**事实来源**。明确指定的模板优先；已有 PPTX 的局部修改通常直接参考现稿，不必浏览整个素材库。

```text
$sykes-shi-ppt 使用本地素材库 [素材库根目录的实际路径]，先阅读 [索引文件的实际路径]。
请为这次 [汇报用途] 选择一份主要视觉模板，参考它的配色、字体和标题样式；
按本次材料 [事实资料路径] 制作 [页数] 页，文字和图表需要可编辑。
其他案例仅供版式参考，不要沿用旧项目的事实或数字。完成后逐页检查。
```

如果你已有明确选择，可以直接写“只使用 `[模板路径]` 作为视觉参考”。如果需要严格沿用源模板，说明要保留的母版、版式或页面；如果只要求“同风格”，可以在保留主要视觉规则的同时按内容重新设计页面。

Codex 会依据本次请求和实际可访问的文件按需查找；它不会因安装本技能而自动建立索引、监控目录或扫描整座素材库。没有预先准备素材也可以开始任务，再提供必要的参考文件。

## 6. 一组路径示例：建库后开始制作

假设 Windows 用户把有权使用的文件放在 `D:\个人资料\PPT素材库`，将索引和预览放在 `D:\PPT工作区\素材索引`，本次资料在 `D:\PPT工作区\本次资料`，最终文件交付到 `D:\PPT工作区\交付`。这些只是示例；确保路径存在并改为自己电脑上的实际位置。macOS 或 Linux 用户可以分别使用 `~/Documents/PPT素材库`、`~/Documents/PPT工作区/素材索引`、`~/Documents/PPT工作区/本次资料` 和 `~/Documents/PPT工作区/交付` 等本地路径。

首次整理时，使用第 4 节的提示词，分别填写素材来源和索引工作区；索引开头记录源素材库根目录。新建汇报任务时，再同时提供素材库、索引、本次事实资料和交付目录，例如：

```text
$sykes-shi-ppt 请读取素材库 D:\个人资料\PPT素材库 和索引 D:\PPT工作区\素材索引\索引.md，
为一份 3 页进展汇报选择合适的参考；本次事实资料在 D:\PPT工作区\本次资料。
历史材料只作风格参考。请制作文字和图表可编辑的 PPTX，逐页检查后
保存到 D:\PPT工作区\交付。
```

工作环境需要能访问这些路径；如果目录权限不足或使用远程环境，应先解决访问问题。不要在不知道素材去向的情况下将私人资料交给外部服务。
