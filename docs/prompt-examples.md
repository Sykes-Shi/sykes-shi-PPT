# 新建任务提示词示例

以下示例可以直接复制到新的 Codex 任务中，再把 `【方括号】` 替换成自己的内容。文件和目录路径使用本机实际可访问的位置；没有相关要求的行可以删去。指定 `$sykes-shi-ppt` 后，技能会结合当前任务和可用工具执行，不需要填写所有字段。

建议把任务工作区和素材库放在不同的本地目录。素材库由使用者自行准备：示例中要求读取目录、生成索引或选择参考时，是在本次任务中明确交办这些工作，并不表示安装技能后会自动扫描或登记素材。

仅指定技能不等于指定某一份模板。希望严格沿用特定模板时，请在提示中明确给出文件和使用范围；希望技能选择参考时，提供可访问的素材库位置即可。

## 1. 基于指定的唯一参考制作

```text
$sykes-shi-ppt 请根据【事实资料的路径或附件】制作【页数】页 PPT，
用于【场景】，听众是【受众】，交付【PPTX 保存位置】。

请以【参考 PPTX 路径】作为唯一视觉参考，延续其版式、颜色、字体、
页面元素和画幅；根据每页内容选择合适版式。事实和数据只使用我提供的资料，
不要沿用参考稿的示例文字、数字和截图。

文字、表格和需要更新的数据图表保持原生可编辑。请逐页渲染检查后交付；
可以根据现有信息自主决定细节，不必逐阶段等我确认。
```

严格匹配母版或某些指定页面时，可以补充“第【页码】页对应参考稿第【页码】页，保留其布局和元素位置”。资料用途只作事实来源时，也应在提示中写清，避免把它误当视觉模板。

## 2. 从本地素材库选择参考

```text
$sykes-shi-ppt 我有一份本地参考素材库：【素材库根目录】，索引文件为【索引路径；没有可删除】。
请根据本次【用途和受众】、【页数】以及【内容资料路径】，
从中挑选适合的 PPTX 作为视觉参考；按需查看实际页面，说明所选参考及其用途。

事实以本次资料为准，历史参考稿只用于风格或版式。不要修改原始素材；
根据选定的视觉体系制作可编辑 PPTX，文字、表格及需要更新的数据图表保持原生。
请渲染并逐页检查，将成品保存至【交付位置】。
```

如果希望优先考虑某个文件或页型，可以补充“优先看【文件或页码】”；如果某份资料只作事实来源，请在提示中注明。

## 3. 制作一页汇报

```text
$sykes-shi-ppt 请把【资料或需要表达的内容】整理成一页可编辑 PPT，
用于【场景】，供【受众】在【预计时间】内了解【核心问题】。
视觉参考：【模板路径或素材库目录】；事实来源：【资料路径】。

请突出【重点】，保留必要的数字、时间和限定；不要为了填满页面添加未经提供的结论。
文字、表格和需要修改的图表保持可编辑。完成后渲染并检查可读性、
对齐、数据和裁切，保存到【交付位置】。可自主处理版式细节。
```

## 4. 制作整套汇报

```text
$sykes-shi-ppt 根据【资料路径】制作一套【页数或汇报时长】的汇报，
主题是【主题】，用于【场景】，听众是【受众】。
希望讲清【需要回答的问题】；应保留【必需内容】。

视觉参考：【指定模板或本地素材库目录】；参考只用于版式和风格。
根据内容选择标题、图表、流程图或表格，保持全稿视觉统一并适当变化布局。
默认交付可编辑 PPTX，文字、表格和需要更新的数据图表保持原生；
需要插图时可在【允许范围】内使用生成图片。

资料足够时请直接完成，不必依次等待大纲、样页和工具选择确认；
缺少会实质影响结果的信息时再向我确认。逐页渲染核查，输出到【交付位置】。
```

## 5. 修改已有页面并保留动画

```text
$sykes-shi-ppt 请在【源 PPTX 路径】的副本中修改第【页码】页：
【具体修改内容】。更新所需数据见【资料路径】。

请保持其余页面、主题、母版、备注、原有动画、切换、隐藏页和内部跳转；
如果本次只调整格式、封面或图表位置，请保留原有正文，不进行文字改写。
修改前检查受影响对象及依赖。按实际修改范围核对图表数据和动画目标，
渲染受影响页面并检查整份交付稿。若需要特定软件的播放检查，
请在【目标软件】中测试并说明实际检查结果。
输出到【新文件路径】，保留源文件。
```

## 6. 配套讲稿或备注

```text
$sykes-shi-ppt 请根据【最终 PPTX 路径】和【事实资料路径】编写配套讲稿，
用于【场景】，面向【受众】，总时长约【分钟】。

按最终页序组织讲稿，结合内容需要串联背景问题、能力或方案、
应用场景、实际案例和业务价值；技术内容可按输入、方法、输出和用途解释。
只采用资料中有依据的事实和数字。语言要适合现场表达，保留必要转场；
对未提供或尚未确定的信息不要自行补成结论。
请将讲稿【写入对应页面备注／另存为文档】，交付到【位置】，并核对页码与讲稿的对应关系。
```

## 7. 数据图表和比较页面

```text
$sykes-shi-ppt 请根据【数据表路径】制作【页数】页【趋势／比较／进度】展示，
供【受众】了解【问题或结论】。视觉参考：【模板路径或素材库目录】。

核对数据口径、单位、时间范围及图表与数据表是否一致；
对比项目采用一致的尺度和含义明确的颜色。需要精确比较时可使用表格。
图表及其数据需要在 PPTX 中可编辑；必要时保留来源、说明和有意义的限定。
逐页渲染检查，输出到【交付位置】；未提供的数据不要编造。
```

## 8. 只读审阅现有演示文稿

```text
$sykes-shi-ppt 请只读审阅【PPTX 路径】，重点检查【内容准确性／版式／
可读性／图表／动画与交互】。参考资料或核对依据是【路径；没有可删除】。

请先检查实际页面，按影响程度列出问题、页码和可执行建议；
区分已经验证的问题与需要进一步检查的事项。无需修改或另存 PPT。
```

## 9. 整理并建立本地素材索引

```text
$sykes-shi-ppt 请整理我提供的本地素材目录【素材目录】，用于以后的 PPT 任务。
请先只读查看现有 PPTX、PDF 和图片，区分可编辑模板、视觉参考和其他素材，
按需生成页面预览，并记录每份材料的用途、适合页型、可用范围和必要注意事项。

请把索引和预览保存在【仓库及云同步目录之外的本地索引目录】，
索引开头记录素材库根目录，文件相对路径以该根目录为准。
不要修改或移动原始素材，也不要把素材、索引和预览上传到 GitHub 或外部服务。
索引只用于我自己，涉及原始文件内容时按原资料的保密要求处理。
完成后告诉我，以后如何在新任务中指定这个目录和选用参考。
```

以上做法是按本次提示整理资料；以后发起新任务时，仍需提供素材库或索引的位置，供 Codex 在当前任务中读取。PDF 和图片通常适合提供视觉参考，若需要沿用可编辑对象，应提供对应的原始 PPTX 或其他源文件。
