# 页面设计与制作细节

这份指南提炼了本技能的常用做法。实际任务以用户指定的模板、页面范围、内容和交付要求为准；以下方法按需要选用，不要求每份汇报使用固定页数或固定结构。

## 从沟通目的选页面

| 页面目的 | 可以采用的表达方式 | 需要注意 |
| --- | --- | --- |
| 情况概览 | 少量关键数字、简洁说明及必要的时间范围 | 指标要有来源和口径，不为凑版面虚构数字。 |
| 项目进展 | 时间线、里程碑或已完成／在推进事项 | 区分已经完成、正在进行和计划开展。 |
| 方案比较 | 统一项目、单位和假设条件的对照表，必要时先分项后汇总 | 对比对象、统计期间和条件保持一致。 |
| 前后变化 | 相同位置、尺度和标签的前后两页，突出关键变化 | 只有条件可比时才直接比较；动画须实际检查。 |
| 业务或技术流程 | 清晰的输入、处理、输出和用途，配合必要连接线 | 将真实流程、拟议方案和示意概念区分清楚。 |
| 数据趋势 | 原始数据驱动的折线图或其他适合的图表 | 标明单位、数据口径和来源；可编辑时核对内嵌数据。 |
| 任务计划 | 从目标时间倒排关键节点，将任务、时间和责任对应展示 | 不虚构责任人、时限或依赖关系。 |
| 现场说明或决策 | 背景、必要证据、可选方案与需要的决定 | 只有材料支持时才写结论；普通介绍页无需硬加决策建议。 |

标题可根据内容使用主题式标题或结论式标题。结论式标题应有当前资料支持。封面、目录、章节页和结束页按实际需要使用，单页任务不必套入整套结构。

## 严格套用与同风格设计

- **严格套用**：使用指定 PPTX 的相应页面、母版和源对象，保留用户要求的封面、目录、章节页、页眉页脚及其他固定元素。实际需要修改的文字和数据按任务更新。
- **同风格新建**：参考指定材料的色彩、字体、标题层级和重复元素，正文布局可以随信息重新设计。用户也可以单独指定封面、目录、章节页沿用模板，其余页面按内容设计。
- **多个参考**：先确定一个主视觉体系，其他材料只补充适合的页面结构或表达方式。不要将风格参考中的旧数据、标题或结论移到新稿。

只调用本技能时，不意味着用户已经指定某个模板；可以根据提供的参考或素材库按任务选择。任务只要求移动图片、调整字号或转换格式时，保留既有文字，不借机改写正文。

## 页面语言和讲稿

正式汇报重视清晰、克制、重点突出：用明确的标题建立页面层次，以图表、证据和必要文字解释问题，避免把装饰性元素当作内容。页面拥挤时，先删去重复、重新组织或在允许的页数内拆分，避免靠明显缩小字号解决。

用户需要面向领导的讲稿时，可按实际材料组织“背景或问题 → 能力 → 应用场景 → 案例 → 业务价值”；技术内容可以按“输入 → 方法 → 输出 → 用途”解释。这个顺序是可选的叙事方法，不是所有任务的强制结构。PPT 负责提示重点和呈现证据，讲稿补充解释和自然转场；页面顺序调整时同步检查备注。

## 编辑形式与证据

- **原生可编辑**：标题、正文、表格、需要更新数据的图表和所需图示保留可编辑对象。
- **混合制作**：场景图、背景或插图可用生成图片，准确文字、数据、真实标识和截图使用原生对象或获准的原件。
- **整页图片**：用户明确接受图片页时可使用，并说明编辑形式。若需把图片重新做成可编辑 PPTX，应单独处理并核对可恢复的文字和数据。
- **示意与真实结果**：未来方案、重建界面和模拟数据按实际状态标识；真实数据和结果应从当前材料核对。

风格参考与事实资料分开。除非用户明确授权，不向外部服务发送内部资料。确有必要使用生图时，明确哪些是风格参考、哪些是必须准确保留的原始素材。

## 完成前检查

渲染最终成品并逐页检查：是否有错字、文字溢出、遮挡、图片变形、图表标签不可读或页面顺序错误；核对数字、单位和来源，以及要求可编辑对象是否可修改。局部修改带动画或交互的稿件时，额外检查隐藏页、跳转、备注和动画目标；需要 WPS 或其他指定软件测试时，在对应软件中验证并按实际结果说明。缺少必要能力时，保留已完成成果并说明未完成的检查。
